# История изменений

## 0.5.0 — 2026-11-07

- Синхронизация исходников с рабочей версией после опубликованной 0.3.2. В релиз входят изменения 0.3.3–0.4.3 и описанные ниже LLDP и перенос конфигурации.
- Удалён незавершённый код встроенного обновления, который не был подключён к интерфейсу и мешал проверке типов. Обновление выполняется через GitHub Releases.
- Добавлены воспроизводимый workflow для обычной и Legacy редакций, проверка версии тега и SHA-256 файлов.
- Переписаны описание проекта и инструкция по выпуску релизов.

## В разработке — автоматический LLDP и перенос community

- LLDP автоматически читается при сохранённом community и включённом SNMP, включая наследование от папки. Стартует после изменения настроек, импорта или запуска приложения; повторяется раз в 5 минут. У хоста есть выключатель автосбора и статус результата.
- Автосбор ограничен двумя одновременными хостами, использует только сохранённые адреса, отменяет устаревшие запросы и сохраняет последний успешный снимок при ошибке. Фоновые данные защищены от перезаписи устаревшей карточкой через ревизию LLDP.
- Экспорт явно включает пароли и SNMP/LLDP community в один зашифрованный блок. Проверены перенос community хоста и папки, наследование, настройки SNMP, выключатель LLDP и повторное шифрование на получающей машине.

## В разработке — перенос учётных данных

- Для экспорта с зашифрованными паролями импорт теперь требует пароль файла в интерфейсе и основном процессе. Пустой пароль больше не приводит к молчаливому переносу без секретов.
- «Импорт из другой базы» распознаёт экспорт Pult и направляет в «Перенос конфигурации → Импорт». Рабочий `store.json` также не принимается как сторонняя таблица: перенос паролей требует экспорта на исходном ПК.
- В режиме «Добавить новое» явно указано, что существующие логины и пароли не обновляются. Добавлен `npm run test:transfer`: проверка шифрования, импорта между двумя изолированными тестовыми системами, наследования логинов и паролей, неверного/пустого пароля, повторного импорта и выбора неверного раздела.

## В разработке — LLDP для хостов

- В карточке хоста появился раздел «LLDP · соседи»: ручное чтение LLDP-MIB по SNMP v2c, порты, Chassis ID, management IP и привязка соседа к существующему хосту. Совпадения по ID/IP показываются как кандидаты; имя само по себе не создаёт привязку.
- Данные сохраняются вместе с хостом кнопкой «Готово» и входят в экспорт конфигурации. Ошибка, неполный ответ или отмена не заменяют предыдущий снимок. Опрос не запускается при открытии карточки и не меняет конфигурацию оборудования.
- Добавлена полностью локальная проверка `npm run test:lldp` с поддельным SNMP-транспортом. SSH-сбор и построение связей на карте в этот этап не входят.

Обе редакции собираются из одних исходников и всегда выходят с одним номером версии:

- **Pult** — Windows 10 и 11 (Electron 44).
- **Pult Legacy** — Windows 7, 8.1, Server 2012 и 2012 R2 (Electron 22, последний, что на них запускается). Функции те же, см. [legacy-2012/README.md](legacy-2012/README.md).

Релиз на GitHub публикуется только для последней версии. Более ранние версии ниже описаны для истории, отдельных релизов у них нет.

## 0.4.0 — 2026-10-23

- **Переподключение сессии.** При обрыве сессия не закрывается: в заголовке панели кнопка «Переподключить» (и Enter в терминале). Подключение идёт в том же окне и вкладке, под тем же id, прежний вывод остаётся выше. Над сеткой «Переподключить: N» для всех отключившихся, в меню вкладки группы «Переподключить отключённые».
- **«Назад» по папкам.** Кнопка «‹» слева от хлебных крошек в «Хостах», Alt + ← и боковая кнопка мыши. Возвращает в предыдущую открытую папку, без истории поднимает на уровень выше.
- **Заставка при запуске.** Небольшое окно с логотипом, названием редакции и версией, пока грузятся база и интерфейс (от 1,2 до 10 с).
- **Безопасность.** Импорт конфигурации в режиме «Заменить всё» больше не меняет путь к WinBox: файл с другого ПК не может выбрать, какую программу запустит Pult.
- Сборка без доступа к GitHub описана в ARCHITECTURE.md, раздел 17.

## 0.4.1 — 2026-10-26

- **Автоматическое переподключение SSH.** При обрыве соединения Pult повторно подключается в той же панели и сохраняет прежний вывод. Интервалы между попытками растут от 2 до 30 секунд; доступно в основном и отдельном окне. Ручное переподключение остаётся доступно.

## 0.4.2 — 2026-10-26

- **Переподключение к Huawei.** При сбросе соединения с уже запомненной парой KEX Pult сразу повторяет handshake с полным списком алгоритмов, без ожидания повторных попыток очереди.
- **Защита повторно используемых сессий.** Поздние события закрытого SSH-клиента больше не могут закрыть новую сессию с тем же ID.

## 0.4.3 — 2026-10-26

- **Редакция для старых Windows переименована в Pult Legacy.** Установщик и portable-файл используют префикс `Pult-Legacy`; старый appId сохранён для обновления установленной редакции.
- **Быстрый повтор SSH-подключения.** Ошибки `ECONNRESET` после завершённого SSH-рукопожатия больше не запускают две лишние попытки с паузами 1,5 и 3 секунды. Автоматический повтор очереди остался только для обрыва до handshake.
- **Быстрый обмен ключами с Huawei.** Даже в профиле «Старые в приоритете» современные методы KEX пробуются первыми; старые DH и SHA-1 остаются резервом для устройств, которые их требуют.

## 0.3.13

- Плитки хостов и папок переносят длинные названия и адреса и растут по высоте, текст виден целиком.

## 0.3.12

- Ping: хост «недоступен», только если не ответили три эха подряд. Убирает ложные провалы при опросе раз в 1–2 минуты.
- SNMP: устройство без датчика температуры показывает «нет данных» вместо ошибки; SNMP, который не отвечает, опрашивается реже.
- Сообщения об ошибках закрываются сами через 6–15 секунд.
- Правый клик открывает меню у хостов, папок (и в дереве слева), Workspace, вкладок, листов карты и учёток.
- Двойной клик по хосту подключается.
- Подложка на листе карты: PNG, JPEG, GIF, BMP, WebP или SVG, чтобы расставить хосты по плану этажа.
- Кнопка сворачивания боковой панели, на карте отдельная кнопка прячет список хостов.

## 0.3.11

- Цвета терминала: цвет символов и фона, готовые наборы (в том числе «Зелёный (PuTTY)»).
- Масштаб карточек на карте сети, перенос длинных подписей.
- Первая редакция для старых систем, теперь называется Pult Legacy.

## 0.3.10

- Вход прямо в сессии, как в PuTTY: если логин не задан или пароль не подошёл, терминал спрашивает `login as:` и `password:`, до 3 попыток, потом предлагает запомнить логин и пароль для хоста.

## 0.3.9

- Пачка хостов (лист карты, папка, выбранные) открывается быстрее: напрямую по 8 сессий, недоступный адрес отпускает очередь через 8 секунд; через jump-host по 3 с автоматическими повторами.
- Исправлены зависшие закрытые сессии и долгое массовое подключение, появившиеся в 0.3.8.

## 0.3.8

- Broadcast как в Termius: кнопка включает общий ввод во все сессии на экране, отдельной строки ввода снизу больше нет.
- Удаление папки целиком с подпапками и хостами (или только папки, содержимое уходит уровнем выше).
- До 3 адресов у одного хоста: мониторинг каждого, подключение к первому ответившему.

## 0.3.0 – 0.3.7

- Дизайн-системы Shellwise (6 тем) и Ferrum, своя иконка, название Pult вместо SSH Client (база осталась в `%APPDATA%\ssh-client`).
- Jump-host (мастер-кей с OpenSSH) и SOCKS5-прокси для SSH, веб-морды, WinBox и проверки портов.
- Старое оборудование: профиль «Авто», ssh-dss со своей проверкой подписи, DH group1, ключи разных типов на одном адресе, перебор сочетаний KEX и ключа хоста при отказе, журнал рукопожатия в `ssh-debug.txt` рядом с базой.
- Мониторинг без VTY: ping и SNMP v2c, температура, аптайм.
- Карта сети: вложенные листы, зоны, связи с портами, групповая смена значков и цветов.
- Workspace, вкладки-группы, отдельные окна сессий, сетка без ограничений.
- Перенос конфигурации (JSON, пароли под паролем файла) и импорт из базы другой программы (SQLite, CSV, JSON).
- Сетевые инструменты: ping, трассировка, DNS, порты, скан подсети.
